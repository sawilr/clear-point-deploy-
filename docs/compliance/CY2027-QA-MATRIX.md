# CY2027 — QA / red-team matrix (spec §31) and website gates (spec §27 / §37)

Audit round 2026-10-04 (SPEC-27 / SPEC-31); written and executed against this tree on
2026-10-27, for the spec §35 final report ("QA report: test ID, expected, actual,
evidence, PASS/FAIL"). Every row is checked mechanically by
`scripts/test-cy2027-qa-matrix-2026-10-04.mjs`: the status must be exactly one of
**PASS / FAIL / NOT TESTABLE HERE**, every PASS row must cite at least one executed
assertion as `scripts/<suite>.mjs :: <assertion label>`, every cited suite must be one
`npm test` runs (the SUITES array of `scripts/run-battery.mjs`), every cited label must be
the label of an assertion in that suite — the first argument of `ok(` / `throws(` /
`rejects(` / `ck(` / `check(`, comments stripped, either the complete literal or the
leading literal of a label the suite completes in a loop (cited with its opening quote) —
every NOT TESTABLE HERE row must say who can test it, and the spec text must be verbatim.
A fixture, a message payload or a detail string is not evidence. A row that stops being
true fails `npm test`.

How to re-run any citation: `node scripts/<suite>.mjs` (or `npx tsx scripts/<suite>.mjs`
for the older battery suites) and search the output or the file for the label. "PASS"
means the cited assertions executed and passed on 2026-10-27 against this tree; it never
means the live site, the voice agents or GoHighLevel were exercised. Where a case belongs
to Emely/Sofía (GoHighLevel voice agents) or to GoHighLevel configuration, the row says so
and is NOT TESTABLE HERE — the rule in code is a definition the live agents do not execute
(`api/_lib/cy2027/voice-soa.js` is imported by no handler; `VOICE_SOA_ENABLED = false`).

Production facts that qualify every PASS below: `SOA_ENABLED = false` (every SOA
endpoint answers 503); production has no KV store, so the rate limits and the one-time-code
caps are per-instance until the owner provisions it; the evidence store is not configured;
`CY2027_SEND_OTP`, `CY2027_SEND_BENEFICIARY_COPY` and `CY2027_QUARANTINE_STOP` are off.
