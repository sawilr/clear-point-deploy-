### P-2026-10-01 — State the burial condition on the Extra Help resource limit (CMS, LEVEL 2)
- **Rule:** CY2026 LIS resource limits are $16,590 single / $33,100 married, or $18,090 / $36,100 for applicants who tell SSA they expect to use some resources for burial (20 CFR 416.1231). Source: the HPMS memo of 2025-10-31.
- **Published:** 2025-10-31 · **Effective:** 2026-01-01.
- **Current implementation:** Clara says "resource limits about $18,090 single / $36,100 married" (`api/chat.js:376`). The figures file stores the same values.
- **Proposed change (minimal):** in `api/chat.js` say "about $18,090 single / $36,100 married if some savings are set aside for burial; $16,590 / $33,100 otherwise". Add a matching comment in `medicare-figures-2026.ts`. No backstop change is needed if both figures are added to its allow-list (test required).
- **Risk if not done:** low. The wording is hedged ("about", "guidelines", the agency decides), but a caller with $16,600–$18,090 and no burial designation could be led to over-estimate.
- **Not verified:** whether medicare.gov's consumer page also quotes the burial-inclusive pair. The page is JS-rendered, the plain fetch returned no figures, and the browser pane timed out. Check: open https://www.medicare.gov/basics/costs/help/drug-costs in a browser.
- **Source:** https://www.cms.gov/files/document/cy2026-lis-resource-limits-memo.pdf

### P-2026-10-02 — Readiness for "$90 Medicare rebate" questions (CMS, LEVEL 2, optional, time-limited)
- **Rule:** MIF Premium Rebate, one-time $90 in October 2026 (DB `FED-2026-MIF-REBATE`).

- **Shelf life:** about through December 2026. If not approved by then, drop it.
