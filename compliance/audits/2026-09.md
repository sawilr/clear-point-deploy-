## Proposals — STATUS: AWAITING OWNER APPROVAL

### P-2026-09-01 — Label-safe 2027 Part D figures for AEP (CMS, LEVEL 2)
- **Rule:** CY2027 Part D defined standard benefit — deductible $700, OOP threshold $2,400 (DB `FED-2027-PARTD-PARAMS`).
- **Published:** 2026-04-06 · **Effective:** 2027-01-01 · PY2027 marketing opens 2026-10-01, AEP 2026-10-15.
- **Current implementation:** Clara states only the 2026 values, correctly labeled "(2026)". During AEP, callers are choosing 2027 plans, so "$2,100 cap" is accurate but not the number that governs the plan being chosen.
- **Proposed change (minimal):** add a separately labeled "For 2027 plans" line (Part D $700 / $2,400) to the `api/chat.js` prompt and a FUTURE block in the figures file, keeping 2026 CURRENT until 2027-01-01. The backstop already leaves figures in windows naming another year untouched (`api/_lib/medicare-figures.js:37`), so it needs a test, not a rewrite.
- **Risk if not done:** low (no false statement); lower-quality AEP answers. **Risk if done wrong:** a 2027 value stated as current → must pass the full battery + backstop suite.
- **Source:** https://www.cms.gov/files/document/2027-announcement.pdf (Table V-2).

### P-2026-09-02 — One NJ MSP referral number across both bots (NJ, LEVEL 2)
- **Finding:** Clara (`api/chat.js:115`, `:1305`) sends NJ MSP callers to the NJ Medicaid hotline 1-800-356-1561; Zara and the official NJ MSP page use NJSave / DoAS hotline 1-800-792-9745.
- **Both numbers are official and live**, so nothing is false. The DoAS number is the one the MSP page names for QMB/SLMB/QI applications.
- **Proposed change:** give the NJ MSP route as "NJSave or 1-800-792-9745 (NJ Division of Aging Services)", keeping 1-800-356-1561 as the general Medicaid line.
- **Source:** https://www.nj.gov/humanservices/doas/services/l-p/msp/

### P-2026-09-03 — High-income MSP guard ignores the state (NY/CT, LEVEL 2)
- **Finding:** `src/lib/customerServiceEngine.ts:5649` — at `inc >= 3000` monthly, the reply says "you may be above the usual income limits for some assistance programs like MSP" for every state (comment cites "NY ~$2,400 single"). Official 2026 limits above $3,000: **CT** SLMB $3,073 / ALMB $3,272 single, $3,806–$4,437 couple; **NY** QI couple $3,375.
- **Impact:** hedged, conditional wording and an advisor is always offered, so this is not a false eligibility decision. But a CT single at $3,000–$3,272, or a CT/NY couple under their limit, is steered away from a program they may qualify for.
- **Proposed change:** make the threshold state-aware, reading from `MEDICARE_2026.msp[state]` (highest single/couple limit per state, with `state.zipCode` already in the engine). If the state is unknown, use the highest served limit (CT ALMB) or leave out the "above the limits" sentence. Add EN+ES regression cases at CT $3,100 single and NY $3,300 couple.
- **Sources:** portal.ct.gov DSS MSP eligibility page; health.ny.gov MSP page (Rev. 3/26).
